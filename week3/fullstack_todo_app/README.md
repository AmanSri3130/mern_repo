# Full Stack To-Do Application

A complete full-stack task manager app connecting Express & MongoDB backend with React frontend.

## Features
- **User Authentication**: Register & Login with JWT authentication stored in localStorage.
- **Protected Routes**: React Router handles protected client-side routes.
- **Task CRUD Operations**: Create tasks with priority badges, toggle complete status, and delete tasks.
- **Modern UI**: Styled with responsive dark theme components.

## How to Run

### 1. Backend Setup:
```bash
cd backend
npm install
npm run dev # Starts on http://localhost:5003
```

### 2. Frontend Setup:
```bash
cd frontend
npm install
npm run dev # Starts Vite server
```
