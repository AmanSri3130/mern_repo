# Social Media Feed Application

A real-time social networking feed web app featuring user registration, posts creation, likes, comments, and WebSockets integration (`Socket.io`).

## Features
- **Real-Time WebSockets**: Live broadcast of new posts, likes, and comments via Socket.io.
- **User Authentication**: JWT Token authentication & password encryption with `bcryptjs`.
- **Interactivity**: Like/unlike posts dynamically and comment in real-time.

## How to Run
- **Backend**: `cd backend && npm install && npm run dev` (Runs on port 5007)
- **Frontend**: `cd frontend && npm install && npm run dev`
