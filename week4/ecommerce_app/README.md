# E-Commerce Web Application

A full-stack e-commerce platform with product management, user authentication, shopping cart, order placement, and an Admin dashboard.

## Features
- **Public Storefront**: Browse products and add items to cart.
- **Shopping Cart**: Real-time total calculation and persistent cart storage.
- **User Authentication**: Register as customer or admin, JWT token authentication.
- **Order Management**: Customers can view order history; place orders with shipping info.
- **Admin Dashboard**: Create products, view inventory, and delete items.

## How to Run
- **Backend**: `cd backend && npm install && npm run dev` (Runs on port 5006)
- **Frontend**: `cd frontend && npm install && npm run dev`
